# Аналитика прокуратуры РК — областной уровень

Демонстрационный локальный прототип на Streamlit. Данные вымышленные; не является сертифицированной ведомственной системой.

## Запуск

1. Установите Python 3.10+ на компьютер.
2. В терминале в папке проекта выполните `pip install -r requirements.txt`.
3. Запустите `streamlit run app.py`.
4. Откройте локальный адрес, указанный в терминале (обычно http://localhost:8501).

## Возможности

- Шесть направлений деятельности прокуратуры.
- Выбор отчётного года, городов и районов, направлений и сопоставимого показателя.
- Сравнение территорий и динамики по годам.
- Демонстрационные сигналы при изменении показателя на 25% и более.
- Контроль обязательных столбцов, дубликатов и пропусков.
- Экспорт таблицы CSV и проекта аналитической справки Word.

## Входной формат

Excel/CSV со столбцами: `год`, `территория`, `направление`, `показатель`, `значение`. Одна строка — один показатель в разрезе года, территории и направления.

Важно: числовые показатели не нормированы на население или число дел. Сопоставимость требует проверки. Нельзя суммировать несопоставимые показатели или делать юридические выводы только по количественной статистике.

## Безопасность

Используйте только вымышленные или официально разрешённые обезличенные данные. Локальный запуск не означает автоматического соответствия требованиям информационной безопасности для ведомственных систем.
